- **AGI Menu 1.15.21: Restart AGI Menu, and Quit no longer turns it off (PHNX-4325).** Settings → AGI Menu has a Restart button and the right-click menu has Restart AGI Menu (⌘R); both run `agents menubar restart`. Quit AGI Menu only quits, and the app returns at the next login. The new Turn off AGI Menu… asks first, then runs `agents menubar disable` as Quit used to. Settings → Tabs names the agents-cli version an unavailable tab needs. Several failing CLI calls finishing at once no longer crash the app. Source: `cli/src/lib/helper-versions.ts`.

- **Re-registering AGI Menu's login item no longer leaves the menu stopped.** `launchctl bootout` returns before launchd finishes removing the job, so the immediate `bootstrap` failed with `5: Input/output error` and the menu stayed down until the next login. Every setup, enable and startup repair that rewrites the plist took this path, including the one-time `KeepAlive` rewrite in 1.23.1. The CLI now waits for the old job to leave (up to 5 seconds), retries a refused bootstrap twice, and prints an error naming `agents menubar setup` if registration still fails. Source: `cli/src/lib/menubar/install-menubar.ts`.
