- **Removed: routines (`agents routines`, the scheduler and catch-up services, routine sync).** Routines never worked reliably, so they are deprecated and gone as of this version. `agents routines` and its old `agents jobs`/`agents cron` aliases are now unknown commands. Also removed with them: the daemon's `scheduler` and `catchup` services, the `scheduler.enabled` device config key, project routine sync and routine device activation, `agents cloud run --on` event triggers, `agents prune cleanup runs`, the `routines:` list in the `fleet:` manifest, the `--routine` filters on `agents ps` and `agents ps focus`, the `agents inspect --routines` drill-down, the `fleet` placement kind (`--where fleet`), session lookup by routine run id, the `routine.start`/`routine.end` events, and the routine fields in JSON output (`jobCount` in `agents daemon status`, `detachedChildren` in `agents daemon stop`, `routines` in `agents menubar snapshot`, `recentRuns` in the factory snapshot, `origin`/`routineName` on `agents ps --json` rows). For scheduled agent work, use OS cron, a systemd timer or launchd and call `agents run` from it, for example `0 9 * * 1-5  agents run claude "triage the open PRs"`. Existing `~/.agents/routines/*.yml` files and leftover `scheduler`/`catchup`/`schedulerEnabled`/`routines:` config keys are ignored rather than rejected, so nothing breaks on upgrade. Source: cli/src/lib/daemon/daemon.ts, cli/src/lib/daemon-services.ts, cli/src/lib/state.ts
