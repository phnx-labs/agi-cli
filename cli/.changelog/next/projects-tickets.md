- **`agents projects tickets` and `agents projects goals`.** A project's Linear issues, one issue, a comment, and its workspace's goals, each one `linear` call scoped by the project's recorded `linear.projectId` with linear-cli's output unchanged. AGI EXT's Project panel reads Linear through these instead of spawning `linear` with a copied board name. A recorded id Linear no longer has gets `Relink it: agents projects link <name> --linear`.
