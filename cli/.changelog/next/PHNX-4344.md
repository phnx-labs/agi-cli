- **`agents ps focus` on a headless session stops it before reopening it in a tab (PHNX-4344).**
  Focusing a session that was running headless used to resume a second copy in a new tab
  while the headless process kept running, so two processes wrote to one conversation. Focus
  now stops the headless process first (here, or with `agents ps stop <id> --local` on the
  device that runs it) and clears its detach record, and opens nothing if that device cannot
  be reached or its `ps stop` exits non-zero. The focus picker does the same for each headless
  session it opens. If the tab then fails to open, the error says the headless run was stopped
  and how to resume it. The tab now goes where your live sessions run (`resolveLaunchBackend`), so from
  AGI Menu it opens in the project's VSCodium window instead of the first installed terminal
  app. A session owned by another device opens a local tab running
  `agents run auto --resume <id> --interactive` when there is no TTY, instead of an SSH hop
  that needs one. A session that has already ended, focused with no TTY, now also opens in
  such a tab instead of resuming in place inside the caller (which failed with no terminal and
  still exited 0). When VSCodium never confirms the tab, focus exits 1 and says to approve the
  "Allow 'Agents' extension to open this URI?" prompt. Source: `cli/src/commands/focus.ts`,
  `cli/src/commands/detach.ts`, `cli/src/lib/terminal/engine.ts`.
- **Sessions from another machine's home now match their project (PHNX-4344).** A session
  recorded on a Linux worker under `/home/<user>/…` now matches a project registered as
  `~/…` on a Mac (and the other way round) when `<user>` is the same user name; `/Users/Shared`
  and other users' homes are not rewritten, so AGI Menu groups those sessions under the right
  project instead of Uncategorized. Source: `cli/src/lib/project-root.ts` (`localizeHome`),
  `cli/src/lib/projects.ts`.
- **`agents projects todo list --project <name>` and `menubar.menu.todoProject` (PHNX-4344).**
  `--project` lists every open issue in that Linear project (an agents project's Linear
  project, or a Linear project name), due ones first, then the newest, at most 6, with
  `total` the full count. The new `menubar.menu.todoProject` key names the project AGI Menu
  lists and files to-dos in, and rides `agents menubar snapshot --json` `menuPreferences`
  when set. Source: `cli/src/lib/quick-todo.ts`, `cli/src/commands/projects-todo.ts`,
  `cli/src/lib/device-config.ts`.
- **AGI Menu shows draft pull requests by default (PHNX-4344).** `menubar.menu.githubDrafts`
  now defaults to `true`; `githubBots` stays `false`. Source: `cli/src/lib/device-config.ts`.
- **`agents ps stop` on another device exits 1 when the remote stop fails (PHNX-4344).** A
  one-shot peer hop (`runOnPeer` without a TTY) now reports a non-zero remote exit as `failed`
  instead of `ok`. Source: `cli/src/lib/session/remote/remote-list.ts`,
  `cli/src/commands/sessions-stop.ts`.
