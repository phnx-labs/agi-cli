- **`agents ps topic <id> <topic>` files a session under a topic you choose (PHNX-4676).** A session's topic is its `workstream`, the name AGI EXT groups the Sessions list by; until now only the daemon's title job wrote it. The topic you set is stored on the machine that owns the session (the command hops there over SSH, like `ps stop`), marked as yours, and the title job never overwrites it, even on `agents daemon index backfill titles --refresh`. Your other machines see it with the next session sync. `--json` prints one result line for a UI; AGI EXT runs it when you drag a card onto another section. Schema v56 adds `sessions.workstream_set_by_user`. Source: `cli/src/commands/ps-topic.ts`, `cli/src/lib/session/db.ts`.
