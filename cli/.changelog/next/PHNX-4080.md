- **Resuming a session with no transcript now fails loud (PHNX-4080).** `agents sessions
  resume <id>` / `agents run --resume <id>` used to answer a transcript-less session id by
  launching a fresh agent whose prompt was `/continue <id>` — it read nothing, reported
  there was nothing to continue, and idled (burning account headroom on the way). Recovery
  now refuses such an id up front and names the harness and cwd a replacement run needs.
  A row resolved from a peer is exempt: its path is the peer's to judge, so the
  owner-unreachable `/continue` replay from the synced mirror still works.
  Source: `cli/src/lib/session/recovery.ts`.
