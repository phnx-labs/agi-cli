- **The session index now persists `firstUserMessage` — the full genuine first user turn — and surfaces it on `sessions watch --json` (PHNX-3621).** A consumer that wants to show a session's real opening prompt (the AGI EXT Sessions "THE ASK" line) previously had only `topic` (a truncated first-line summary), `label` (an agent/user-set title), or a live-row `userPromptClean` (a display-cleaned turn) — none of them the actual full prompt, and none available without re-reading the transcript. Every harness scanner that can locate a first user turn now captures it verbatim at scan time (claude/codex resumable-state parsers, gemini/rush/hermes/muse/droid/antigravity/cursor/kimi/grok/opencode), persists it in `sessions.first_user_message`, and reads it back into `SessionMeta.firstUserMessage`. Running `--active` rows and the canonical `SessionWatchRow` are backfilled from the index exactly like `version`/`account`, so the watch stream carries the real prompt with **no side-channel fetch**. Additive and backward-compatible: old rows read the field as absent and re-derive it on their next scan (paired `CONTENT_INDEX_VERSION` bump). OpenClaw is out of scope — its index rows are a live channel/cron inventory with no transcript. Source: `cli/src/lib/session/discover.ts`, `cli/src/lib/session/db.ts`, `cli/src/lib/session/active.ts`, `cli/src/lib/session/remote/watch.ts`, `cli/src/lib/session/types.ts`.
