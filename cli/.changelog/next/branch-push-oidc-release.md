- **CLI releases now publish from a versioned branch through GitHub OIDC.** Push `release/x.y.z` or `release/x.y.z-pre.n`; one GitHub-hosted workflow derives the exact release-tree attestation from the newest compatible tested proof in the `main` ancestry, builds and install-smokes the bound tarball, creates `v<version>` plus its GitHub release, and publishes the same bytes to npm with provenance. Pre-releases use the `next` dist-tag. The former home-base/token publisher and its dead `NPM_TOKEN` auth probe are removed, so there is no stored npm credential or second publisher. Source: `.github/workflows/release.yml`, `cli/scripts/release-ci.sh`, `cli/scripts/release.sh`.
