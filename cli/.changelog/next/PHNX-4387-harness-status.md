- **A Claude turn quiet for over two minutes stays working (PHNX-4387).** Claude writes nothing to its transcript while it thinks or streams one long tool call, so `agents ps` and the session sidebar flipped a live turn to idle after two minutes. The live-state read now takes the turn state Claude Code reports in `<config>/sessions/<pid>.json` (sessions-cli 0.8.6 `readHarnessStatus`): busy is working (for up to 30 minutes of transcript silence), idle means the turn ended, and a harness that reports nothing keeps the two-minute window. This holds even when the transcript tail holds only request records, where the row used to read `unknown`. A quiet working row shows `quiet Nm` where it showed `idle`, and `agents ps --json` rows carry `quietSinceMs`, when the turn went silent. Source: `cli/src/lib/session/active.ts`, `cli/src/commands/ps-roster.ts`.
