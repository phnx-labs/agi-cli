- **Fix `sessions resume` terminal surfaces for multiword prompts and `--device` cwd (PHNX-3940).** The batch picker's selected-resume command reached every terminal backend unquoted, so a picked session's follow-up prompt (or any argument with spaces) was split into several shell words by the backend's `command.join(' ')` boundary instead of riding through as one argument; it now shell-quotes each word the same way `run-surface.ts`'s `buildRunCommand` does, while `spawnCliInPlace`'s no-tab-backend path keeps the original raw argv (`spawn` takes literal argv, no shell). Separately, a `--device` surface's working directory was probed with `fs.existsSync` against the *local* filesystem, which silently swapped in this box's cwd whenever the session's recorded cwd (e.g. a remote `/home/...` path) didn't exist locally; it now trusts the already-validated origin device's recorded cwd and lets that device validate it. Source: `src/commands/sessions-resume.ts`.
