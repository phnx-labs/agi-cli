- **`agents projects prs <project>` — every open PR across a project's repos (PHNX-3999).** Reads the whole open PR board (drafts included, no author filter) straight from GitHub over REST, paginated, for the project's own attached repos only — unlike `projects status`, whose `openPrs` only carries PRs the fleet's sessions opened. `--repo <owner/repo>` restricts to one attached repo; `--repo … --number <n>` lazily enriches exactly that PR with its head-SHA checks and reviewDecision. A per-repo fetch failure is reported and marks the result partial, never relabeled as zero open PRs. Source: `cli/src/lib/github/project-prs.ts`, `cli/src/commands/projects.ts`.
- **AGI Menu preferences are registered `agents config` keys (PHNX-3999).** Thirteen user-scope `menubar.menu.*` keys (defaultProject, workingRowsShown, showPreviews, projectPriorityFilter, hideCompletedMilestones, bannerWhenNeedsYou, includeOtherDeviceRequests, groupBy [none/project/agent/device], thenBy, projectScope, projectSort, ticketSort, showPullRequests) that get/set/unset/list through the existing `agents config` surface and sync fleet-wide via the central `agents.yaml`. `config list --json` emits `{key,value,hint}` and omits unset keys, so the menu falls back to its own defaults. `agents menubar snapshot --json` also carries a `menuPreferences` map (effective value per key, `defaultProject` omitted when unset) so the menu reads them from the snapshot it already polls, not a second mechanism; on macOS a one-shot, sentinel-gated migration lifts legacy `com.phnx-labs.agents-menubar` UserDefaults into config without overriding an already-set value. Source: `cli/src/lib/device-config.ts`, `cli/src/lib/config-keys.ts`, `cli/src/commands/config.ts`, `cli/src/lib/menubar/snapshot.ts`, `cli/src/lib/menubar/migrate-prefs.ts`.
- **Devices carry a `formFactor` hardware fact (PHNX-3999).** A new shared device-scope config key (`laptop`/`desktop`/`server`/`unknown`) set explicitly per device — never inferred from the OS platform — surfaced in `agents menubar snapshot --json` so the menu can draw a factual hardware icon. Source: `cli/src/lib/device-config.ts`, `cli/src/lib/menubar/snapshot.ts`.
