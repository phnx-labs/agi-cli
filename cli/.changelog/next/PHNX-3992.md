- **Artifact sharing moved out to the standalone `artifacts` CLI (breaking).**
  `agents artifacts`, `agents artifacts share` (and its `list`/`delete`/`open`/
  `visibility`/`edit`/`revisions`/`update`/`setup`/`join`/`status`/`analytics`
  subcommands), and `agents artifacts setup` are removed — artifact sharing now
  lives entirely in `@phnx-labs/artifacts-cli` (`artifacts share …`,
  `artifacts auth login`), mirroring the secrets (PHNX-3989) and computer
  (PHNX-4075) extractions. Install it with `npm i -g @phnx-labs/artifacts-cli`.
  `agents sessions share <id>` stays — it
  renders the session locally and now publishes through `artifacts share`, so it
  needs that CLI installed. `agents traces` and `agents sessions export`/`backup`
  are unaffected (their own Cloudflare/R2 paths). The ordinary CLI release no
  longer deploys the managed share Worker (`--deploy-worker` is gone); that deploy
  moved to artifacts-cli's own release. Source: removed `cli/src/lib/share/` and
  `cli/src/commands/{artifacts,artifacts-setup,share}.ts`; the generic Cloudflare
  provisioning primitives `agents traces`/`agents sessions backup` borrowed now
  live in `cli/src/lib/cloudflare/provision.ts`.
