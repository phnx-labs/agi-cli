- **Every harness's session row on `agents feed watch --json` now carries
  `model` (PHNX-4330).** Grok, Droid, OpenCode and Cursor rows never had one,
  and most history rows lost it. `@phnx-labs/sessions-cli` 0.8.4 reads the
  model each transcript records (Grok `model_id`, Droid `modelId` or its
  `settings.json`, OpenCode `modelID`, Kimi `llm.request`, Cursor's chat
  `store.db`). History rows now fall back to the indexed `model` when the
  timeline pass never folded the session, and the Grok, Kimi and Cursor indexers
  fill it (a one-time reindex picks up rows already on disk). A live turn longer
  than the 80-event state window keeps its model, carried from the
  already-parsed prefix with no extra reads.
