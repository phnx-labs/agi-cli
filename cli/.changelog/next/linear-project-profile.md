- **A project can live in another Linear workspace (`linear.profile`).** `agents projects link <name> --linear [query] --profile <p>` lists and binds from that linear-cli profile and records `linear.profile` in the project YAML; a re-link without `--profile` keeps it. Every `linear` spawn made for the project (quick to-dos with `--project`, the Lead's tools, brief and process env) runs with `LINEAR_PROFILE=<p>`, the `linear` card line reads its key from the profile (profile config, then the Keychain account `<p>`, never `$LINEAR_API_KEY`), and `projects list --json` / `projects status --path --json` carry `linear.profile`. A project without it behaves exactly as before. Source: `cli/src/lib/linear-projects.ts`, `cli/src/lib/projects.ts`, `cli/src/lib/linear-cache.ts`, `cli/src/commands/projects.ts`.
