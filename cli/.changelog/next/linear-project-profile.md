- **A project can live in another Linear workspace (`linear.profile`).** `agents projects link <name> --linear [query] --profile <p>` lists and binds from that linear-cli profile and records `linear.profile` in the project YAML; a re-link without `--profile` keeps it and `--no-profile` removes it. The name `default` is reserved for the default workspace and refused as a profile. Every `linear` spawn runs with `LINEAR_PROFILE` pinned: `<p>` for the project's quick to-dos, link, the Lead's tools, brief, process and workers, `default` when the project has no profile. `todo done`/`undo` and ticket priority pick the profile from the issue's team key. The `linear` card line reads its key from the profile (profile config, then the Keychain service `linear-api-key.<p>`, never `$LINEAR_API_KEY`), and `projects list --json` / `projects status --path --json` carry `linear.profile`. Needs linear-cli 0.32.0 or later. Source: `cli/src/lib/linear-projects.ts`, `cli/src/lib/projects.ts`, `cli/src/lib/linear-cache.ts`, `cli/src/commands/projects.ts`.
