- **`agents computer` is now a thin consumer of the standalone `computer` CLI (PHNX-4075).** The helper daemons, the JSON-RPC transport, the RFB/VNC client, and the autonomous `run` loop moved to `@phnx-labs/computer-cli`, which releases and self-updates on its own cadence — the same split `secrets` (PHNX-3989) and `sessions` (PHNX-4012) already made. **Install it once per machine: `npm i -g @phnx-labs/computer-cli`**; without it every verb fails loud with that line, and there is deliberately no bundled fallback engine. Every verb, `--device`, `--vnc`, the permission allow list, `agents computer sessions` / `agents sessions --computer`, and `agents setup computer` behave as before. agents-cli keeps what only it can know — the `Computer(<bundle-id>)` allow list rendered from the permissions resource layer, `--device` fleet resolution and its `ssh -L` tunnel, actor/session identity, and the action history — and hands it to the engine as one JSON context on fd 3, receiving NDJSON action events back on fd 4. Per-verb flags and their `--help` are the engine's, so its surface no longer needs a second copy here. The `computer` npm bin, `native/computer-mac`, `native/computer-win`, the two helper publish scripts, and the `computer-mac`/`computer-win` entries in `helper-versions.ts` are removed: this CLI no longer distributes those helpers, so the release manifest no longer attests them. Source: `cli/src/lib/computer-client.ts`, `cli/src/lib/computer/{context,policy,remote,record}.ts`, `cli/src/lib/ssh-tunnel.ts`, `cli/src/commands/computer.ts`, `cli/docs/computer.md`.
