- **`agents computer` now uses the standalone `computer` CLI (PHNX-4075).** Install it with `npm i -g @phnx-labs/computer-cli`; `agents setup computer` also installs it when missing. The standalone package owns desktop commands, native helpers, remote provisioning, and VNC transport. Agents retains fleet device resolution, permission groups, session identity, and action history. The separate `computer` npm executable and native helper sources now ship from the standalone project.
