- **The daemon no longer restarts every few minutes on a Mac with many screen recordings.** Every 2 seconds the `recordings` watcher looked up a session for each recording since `watchedSince`, one full live-session scan per file and all at once, and repeated it on every tick for any file with no single matching session. On a laptop with 77 recordings that meant 77 parallel scans every tick (`ps`, `lsof` and `tmux` per live session), event-loop stalls of 25 to 68 s, and 57 daemon restarts in a day as `attention-notify` ran past its hang limit. A scan now reads live sessions at most once, only when it finds a new file, and a file's lookup is never repeated, including when it matched no session. Source: `cli/src/lib/recordings/settle.ts`.
