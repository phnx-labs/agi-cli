- **Session rows tell the truth about questions, replies, PRs and limits (#3989).** A permission prompt no longer replaces the open question a Claude session is asking, and an `AskUserQuestion` permission request opens nothing of its own, so the question's choices stay answerable. `agents feed answer` types into a session's VSCodium tab when the session has no tmux or iTerm reply rail. Rows carry `prs` when a session opened more than one PR. With `@phnx-labs/sessions-cli` 0.8.7, a session reads as rate-limited only when it is stopped on a limit (not when its tool output mentions 429), a transcript ending in a large compaction line still reads, and pages rewritten under `.agents/artifacts/`, `plans/` or `reports/` count as artifacts. Source: cli/src/lib/feed/feed.ts, cli/src/lib/answer-router.ts, cli/src/lib/session/active.ts
