- **`--device auto` skips boxes with a nearly full disk and honours `preferred` everywhere.** A device with under 20 GiB free on `/` now reads `disk low` in `agents devices list` and is excluded from automatic placement (reason `disk-low`), since an agent that cannot create its worktree does nothing. Memory pressure is judged by free GiB rather than percent used, so a 120 GiB box at 48% no longer reads `busy` and loses every pick to a small idle box. `agents devices pick` (and so `scripts/test.sh`) and `agents teams` placement now apply the `auto-launch.preferred` boost that `agents run --device auto` already did. `agents devices list --json` adds `autoSkip`, the reason auto placement would pass a device over (`off`, `personal`, `desktop`, `not-a-worker`, `offline`, `unreachable`, `loaded`, `disk-low`), or `null`. Source: `cli/src/lib/devices/health.ts`, `cli/src/lib/devices/pool.ts`, `cli/src/lib/teams/scheduler.ts`.
