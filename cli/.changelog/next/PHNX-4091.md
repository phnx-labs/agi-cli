- **Removed `agents pty`; use the standalone `term` CLI instead (PHNX-4091).** The
  PTY engine (`agents pty`, its unix-socket sidecar, and the `sessions inject --pty`
  target) moved to `@phnx-labs/term-cli` (`npm i -g @phnx-labs/term-cli`), published
  separately with the same verbs, flags, and JSON shapes. The OAuth device-code
  driver (`agents fleet login`, `agents auth mint`) now spawns the standalone
  `term` binary instead of an in-repo pty sidecar. Source: `cli/src/lib/term-client.ts`.
