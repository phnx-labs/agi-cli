- **`agents projects prs list <project>` returns in about half the time on a repository with many open PRs.** GitHub works out each PR's merge state (`mergeStateStatus`) when asked, so the one paginated GraphQL list of 100 PRs a page spent about 3 s per page on that field alone, one page after another. The list now asks only for the open PR numbers, then reads the PRs 10 to a query, 12 queries at a time. On `phnx-labs/agents` (115 open PRs) the command went from 5.9 s to 3.0 s (median of 5 runs each), and the JSON is byte-identical. Source: `cli/src/lib/github/project-prs.ts` (`listOpenPrs`).
