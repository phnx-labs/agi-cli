- **A first install no longer turns on hooks and auto-approved commands unless you choose them.** The first-run prompt from `agents add <harness>` (and `agents sync` on a never-synced version) used to pre-select every resource, including the system repo's hooks (scripts that run on every prompt and tool call, such as `main-branch-guard`, which refuses edits in your own checkout) and its permission groups (allow and deny rules that auto-approve commands such as `git push`, `ssh` and `curl`). Both now start unchecked and say what they do in the prompt; commands, skills, rules, MCPs, subagents and plugins stay checked. Accepting the defaults is still one Enter: the checked categories sync whole, with no per-category follow-up. "Select All" still opts into everything. Scripted runs (`--yes`, or no terminal) keep their current selection, so existing fleet setup is unchanged. Source: `cli/src/lib/installations/versions.ts`.
