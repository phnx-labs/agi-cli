- **`agents cloud --provider rush` uses a Rush API key, not the deprecated `rush login` (PHNX-4381).** The provider and `agents cloud transcripts` now call the Rush developer API (`/o/{org}/sessions`: start, read, list, `…/events`, `…/messages`, `…/cancel`) with `RUSH_API_KEY` and `RUSH_ORG`, read from the secrets bundle named in `cloud.providers.rush.secretsBundle` or from the environment (`secrets exec getrush.ai -- agents cloud run …`). Nothing reads `~/.rush/user.yaml` any more. A run no longer needs `--repo`; it takes one repository (sent with `--branch` as a `tree/<branch>` resource), and two `--repo` flags are refused. `--skill` takes a public skill URL. `agents cloud run` loses `--mode`, `-b/--balanced` and `--strategy`, which only the old Rush path read: a key run uses the key creator's own model accounts, and `agents run --cloud --mode …` to Rush is refused. Source: `cli/src/lib/cloud/rush.ts`, `cli/src/commands/cloud-transcripts.ts`.
