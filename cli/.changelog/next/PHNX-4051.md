- **Codex custom agents keep their backslashes.** `agents subagents` wrote the
  Codex TOML body inside `"""` and escaped only the closing quotes, so a
  Windows path or a regex in an `AGENT.md` was mangled by TOML's backslash
  escapes. Backslashes are now doubled first. Fixed alongside four other CodeQL
  findings (terminal-escape scrubbing is a linear scan, prompt tag stripping is
  a fixpoint, R2 key decoding is single-pass, and share-page asset inlining
  treats any non-`file:` scheme as remote); none of those change behaviour on
  ordinary input. Source: `cli/src/lib/subagents.ts`, `cli/src/lib/redact.ts`,
  `cli/src/lib/session/prompt.ts`, `cli/src/lib/session/sync/r2.ts`,
  `cli/src/lib/share/html.ts`.
