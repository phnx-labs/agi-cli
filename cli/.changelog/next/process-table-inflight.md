- **The daemon no longer floods a busy Mac with `ps`.** Scans that asked for the process table while a read was still running each started their own `ps -A`. On a loaded machine a `ps -A` takes seconds, so they piled up: zion had 74 running at once from one daemon, with a load average near 40, and every editor, panel and terminal on it slowed down. Callers now share the read in flight, so there is at most one `ps -A` at a time. Source: cli/src/lib/session/active.ts
