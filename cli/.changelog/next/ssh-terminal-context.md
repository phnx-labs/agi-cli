- **A session opened over ssh reads as a terminal session, not headless.** An interactive session reached through `ssh -tt` (how AGI EXT opens a remote session in an editor tab) runs under sshd with a real pty but no known terminal app, so `sessions --active` labelled it `headless` and the extension filed it under Background. A process with a controlling tty is now `terminal` (with `presence: attached`); detached runs such as daemon jobs and teams stay `headless`. Answering such a session's open question no longer runs `--resume` beside the live process (which would start a second writer on its transcript); with no tmux or iTerm rail to type into, the answer is refused with the recovery hint. Source: `cli/src/lib/session/active.ts`, `cli/src/lib/answer-router.ts`.
