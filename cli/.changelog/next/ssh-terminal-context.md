- **A session opened over ssh reads as a terminal session, not headless.** An interactive session reached through `ssh -tt` (how AGI EXT opens a remote session in an editor tab) runs under sshd with a real pty but no known terminal app, so `sessions --active` labelled it `headless` and the extension filed it under Background. A process with a controlling tty is now `terminal` (with `presence: attached`); detached runs such as daemon jobs and teams stay `headless`. Source: `cli/src/lib/session/active.ts`.
