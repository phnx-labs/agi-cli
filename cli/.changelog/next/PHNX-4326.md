- **Cloud tasks nothing has confirmed for a day no longer show as working (PHNX-4326).**
  A `queued`/`allocating`/`running` task whose last update is over 24 hours old is left
  out of the active list and the feed; `agents cloud list` still asks the provider about
  every unsettled task. Source: `src/lib/cloud/store.ts`.
- **Previous sessions on `agents feed watch --json` arrive with their card text (PHNX-4326).**
  A closed session's row now carries `lastAgentLine`, `request`, `todos`, `artifacts` and
  `importantMessage` like a live row. Before, only 5 of 346 previous rows across the fleet
  had a reply line; on this change's test machine 31 of 41 local previous rows have one
  (the other 10 have no assistant text in their transcript). The text comes from the
  preview digest cached against each transcript, so each transcript is parsed once per
  change: the reset serves what is cached and the stream upserts the rest as it builds
  them. Source: `src/lib/session/remote/watch.ts`, `src/lib/session/preview-digest.ts`.
- **`agents ps preview` takes several ids (PHNX-4326).** `agents ps preview
  <id> <id> --json` prints one array in argument order, each element the single-id
  envelope plus `query`; an id that does not resolve is an element with `error` set.
  One id still prints the single object. See `docs/menubar.md`. Source:
  `src/commands/ps.ts`.
- **`agents ps preview --json` carries `subAgents`, `images` and
  `producedArtifacts`, and `todos` folds Claude's task tools (PHNX-4326).** `subAgents` lists each spawned subagent with its
  status and duration, `images` the last six images the session was given, read or
  wrote that still exist on disk, and `todos` now includes `TaskCreate`/`TaskUpdate`
  checklists. `producedArtifacts` is the list a live feed row's `artifacts` holds.
  See `docs/menubar.md`. Source: `src/lib/session/preview-digest.ts`,
  `src/lib/session/glance-files.ts`.
