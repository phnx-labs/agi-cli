- **AGI Menu's Linear tab and Sessions kind switches have config keys (PHNX-4326).** `menubar.menu.tabOrder` and `hiddenTabs` accept `linear`, the menu's new Linear tab (shown by default; a saved order without it reads back with it appended), and two new booleans, `menubar.menu.showBrowserSessions` and `menubar.menu.showComputerSessions` (default `true`), let the menu's Settings turn browser tasks and computer runs off the Sessions tab. Source: `cli/src/lib/device-config.ts`, `cli/src/lib/config-keys.ts`.
