- **`--mode auto` on Grok runs Grok's own auto mode instead of a flagless run that dies headless.** Grok's spec listed no `auto` mode, so `resolveMode` turned `auto` into `edit`, which passes Grok no permission flag. A headless `grok -p` run then asked before most shell commands, had nobody to answer, and got "User cancelled" on the first one, cancelling every later tool and exiting 0 about a minute in. Every Finder "Variations · Soft" run since the action moved to `grok#socials` ended this way. `auto` now passes Grok's native `--permission-mode auto` (the flag string Claude's `auto` also gets), which runs ordinary shell commands headless, and a headless `plan` request for Grok downgrades to that `auto` rather than to `edit`. Source: `cli/src/lib/agent-spec/agents.ts`, `cli/src/lib/exec.ts`.
