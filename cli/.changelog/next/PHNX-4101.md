- **`agents browser` is now a thin consumer of the standalone `browser` CLI (PHNX-4101).** The
  duplicate in-repo browser engine — the CDP/BiDi/Arc drivers, the browser IPC service, the
  chrome-data/profile store and the network-capture pipeline — is deleted; every verb forwards
  verbatim to `@phnx-labs/browser-cli` (`browser`), which owns the engine and keeps every on-disk
  path the old subsystem used. agents-cli supplies only what the fleet CLI knows: `--device`
  resolved to an SSH target (bound once at `start`), remote-control consent, the acting session
  identity, and the capture/session history behind `agents browser sessions`. The daemon no longer
  hosts the browser IPC service or the browser-task reaper (browser-cli runs its own), and the
  retired `browser` alias shim no longer shadows the standalone binary on PATH. Install it with
  `npm i -g @phnx-labs/browser-cli` or `agents setup browser`. Source: `cli/src/lib/browser-client.ts`,
  `cli/src/commands/browser.ts`, `cli/src/lib/browser/{context,record,sessions-list,paths}.ts`,
  `cli/src/lib/daemon/daemon.ts`, `cli/docs/browser.md`.
