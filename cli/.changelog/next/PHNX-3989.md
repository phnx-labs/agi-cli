- **`agents setup secrets` installs the standalone CLI instead of printing a hint (PHNX-3989).** A machine with agents-cli but no `secrets` binary no longer fails loud on `agents run`. `agents setup secrets` installs `@phnx-labs/secrets-cli@0.1.2` (via `agents clis install secrets` when `clis/secrets.yaml` exists, otherwise `npm i -g` of the same pin) and then runs `secrets migrate`. `agents doctor` lists `secrets` as a host CLI and offers `agents cli install secrets`. Presence still uses `findInPath` (skips `~/.agents/.cache/shims`); postinstall still does not auto-`npm i -g` and still does not write a `secrets` alias shim. Source: `cli/src/lib/secrets-cli.ts`, `cli/src/lib/secrets-cli-install.ts`, `cli/src/commands/setup-secrets.ts`, `cli/src/lib/cli-resources.ts`.
