- **A live Claude session row carries Claude's own recap.** Claude Code periodically writes a recap of the session into its transcript (`away_summary`). The newest one now rides the session row as `recap: { text, at }`, without the "(disable recaps in /config)" hint, on `agents ps --json`, `agents ps watch --json` and `agents feed watch --json`, so AGI EXT can show where a session stands without reading the transcript. It comes from the existing index scan; a session indexed before this version gets it with its next recap. Source: `cli/src/lib/session/discover.ts`, `cli/src/lib/session/db.ts`, `cli/src/lib/session/active.ts`, `cli/src/lib/session/title.ts`.
