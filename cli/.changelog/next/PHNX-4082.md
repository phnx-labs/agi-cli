- **One fewer cold `secrets` process on every command that touches secrets (PHNX-4082).** Each synchronous secrets request spawns a fresh `secrets __serve`, so it pays a full Node boot of the standalone — 0.3–2.6 s on a desktop at load average ~100. The client spent one of those purely to ask which protocol version the standalone speaks, before the first real request of every process. It no longer does: every response envelope already carries `v`, and `parseResponse` checks it on each one. That is also stricter than the handshake it replaces — a standalone that answered the handshake as v1 and a later op as v2 used to surface as "malformed response envelope" and now reports `secrets speaks protocol 2; this agents-cli needs 1`. Measured on `agents run claude`: 7 standalone spawns before, 6 after. Source: `cli/src/lib/secrets-client.ts`, `cli/src/lib/secrets-client.test.ts`, `cli/docs/secrets-client.md`, `cli/docs/specifications.md`.
