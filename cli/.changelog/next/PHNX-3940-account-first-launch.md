- **Every local run launches the account you picked, not the version home (PHNX-3940).** A run that selects an account through the interactive picker, the stale-usage picker, the automatic `balanced`/`available` rotation, or a sign-in launch now carries that exact account's identity and its slot or provider credential through to the spawn, instead of keeping only the binary version and launching the version home. One canonical resolver (`resolveLocalAccountLaunch`) materializes the home and credential reference once, at the local spawn boundary. Rate-limit failover re-resolves each account attempt on the spawn device rather than inheriting the primary's home/credential/config, and a refused attempt's quota is attributed to the account that actually ran. The release version still selects the executable only; the account owns the home. Source: `cli/src/lib/accounting/account-launch.ts`, `cli/src/lib/accounting/rotate.ts`, `cli/src/lib/exec.ts`, `cli/src/commands/exec.ts`, `cli/src/commands/run-account-picker.ts`.
