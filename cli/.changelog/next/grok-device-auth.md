- **grok signs in through its device-code flow.** `agents accounts add grok`, `agents accounts login grok#<name>`, `agents fleet login grok`, and the logged-out hint all run `grok login --device-auth`. Bare `grok login` defaults to `--oauth`, the loopback browser flow, which opens whatever browser profile the OS defaults to, and `fleet login` could not scrape it — its grok row carried no URL/code patterns, so a remote grok login always timed out. The device-code screen prints the URL and code instead, so the human finishes the sign-in in the browser profile they choose, and the fleet scraper now matches the real grok 1.0.30 output (fixture in `cli/src/lib/fleet/testdata/grok-device-code.txt`). Source: `cli/src/lib/harness-auth-capabilities.ts`, `cli/src/lib/fleet/auth-sync.ts`, `cli/src/lib/signin-badge.ts`.
