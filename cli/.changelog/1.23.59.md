- **`agents sync` reaches every synced version, keeps out of your repos, and leaves account-home skills alone.** Bare `agents sync` without `--yes` now reconciles every version synced before, not only the default. An edited skill or command is no longer counted as "new", which made a sync with no terminal print `Skipped resource selection` and write nothing after any upstream edit. A `README.md` or `AGENTS.md` in a repo's `commands/` folder is no longer installed as a command or skill. `agents add --yes` and `agents use --yes` on a never-synced version run a full sync, so `--delete` works on it immediately. Sync no longer rewrites a plugin's `plugin.json` in your repo (the installed copy is repaired instead, and `heal.repairedManifests` is gone from `agents sync --json`) and never overwrites a plugin you edited locally. Account homes prune only what sync put there, so a skill made inside one stays. Source: `cli/src/lib/refresh.ts`, `cli/src/lib/heal.ts`, `cli/src/lib/accounts/slots.ts`, `cli/src/lib/installations/versions.ts`.
