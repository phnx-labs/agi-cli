- **A live process with no readable transcript is `unknown`, not `running`.** Being alive is not evidence that an agent is working. On 2026-10-10 the fleet stream listed 26 such rows as running: headless `codex` and `rush` processes with no session id, folder or title (11 on one machine). They now report `unknown` (phase `idle`, `◌` in `agents ps`); a dead one is still `closed`. Fleet "running" counts drop by those rows, and such a row whose editor window closed stays `unknown` instead of turning `orphaned`. Spec SES-18 says so. Source: `cli/src/lib/session/active.ts` (`resolveFallbackStatus`).

- **A finished Claude session no longer reads as working, and Esc reads as idle.** `@phnx-labs/sessions-cli` 0.8.0: a background task's `<task-notification>` (or a `<system-reminder>`) written after a turn ended no longer counts as "the user spoke last" once the transcript has been quiet past the active window. On 2026-10-10 this was why 5 of 7 "working" Claude sessions on the fleet had been silent 18 to 72 minutes. The Claude live tail is now parsed with interrupts, so a call you stopped with Esc no longer looks in flight. Source: `cli/src/lib/session/active.ts` (`parseLiveTail`).
