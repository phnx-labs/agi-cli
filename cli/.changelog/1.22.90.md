- **`accounts migrate --apply` no longer aborts on a worker whose accounts already hold slots (PHNX-3940).** The daemon's auth-sync provisions a durable slot per account on every worker, so `--apply` hit `Slot already exists` on the first credential-bearing legacy home and cleaned nothing. The plan now routes such a home to `trash` (restorable with `agents trash restore`) with the reason "account already holds a provisioned slot on this device", rewrites any `<harness>@<label>` binding to the account, and clears the stale home record; a canonical install in that state keeps its binary, has its stale home moved to `~/.agents/.history/trash/homes/…` (manifest key `<harness>@<label>#home`), and gets an empty home back. A regular file at the slot path is still not a slot, so the apply-time guard still fails loud on that corruption. Source: `cli/src/lib/accounts/migrate.ts`.

- **AGI Menu delivers attention banners on `UNUserNotificationCenter` with real
  action buttons (PHNX-4004).** The deprecated `NSUserNotification` toast is
  replaced for actionable notices: the banner carries the mapped category, a
  time-sensitive interruption level for a blocked ask, a per-session thread so a
  session's banners group, and the harness avatar as an attachment. The
  persistent menu-bar instance is the delegate; a tapped action runs one bounded

  banner so a notice is never lost.

- **AGI Menu palette: find a screenshot by the text on it (PHNX-4006).**
  Every capture in the palette's screenshot folders (the system `screencapture`
  location, CleanShot's export path, and the clip attachments dir) is now OCR'd
  once, on-device, and indexed so you can search screenshots by the words on them.
  With the palette key, `Cmd-Shift-F` focuses a search field above the strip:
  typing filters the thumbnails to captures whose recognized text matches every
  token (case-insensitive, tokenized AND), newest first, with an `n of m match`
  hint; clearing it restores the newest-six strip. A **more** disclosure expands
  the strip into a grid grouped by hour (last 24 h) then day — each cell shows the
  thumbnail, the time, and the first recognized line — where a click attaches and a
  double-click previews the full image in Preview.app. Nothing leaves the machine:
  recognition runs through Vision locally (`.fast`, no language correction) on a
  background queue, images over 20 MB are skipped and the rest downsampled to
  2000 px before recognition, each capture is keyed by the SHA-256 of its bytes so
  a rename or duplicate is never OCR'd twice, a deleted capture drops out of the
  index (search and grid never return it, and the next scan prunes its row), and
  the index is a local SQLite file at `~/.agents/.history/menubar/screenshots.db`.
  Source:
  `cli/menubar/Sources/MenubarHelper/ScreenshotIndex.swift`,
  `cli/menubar/Sources/MenubarHelper/ScreenshotGrid.swift`,
  `cli/menubar/Sources/MenubarHelper/PromptPanel.swift`.
